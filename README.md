# WND SimSuite

**WND SimSuite** is one dashboard for sim racing tools: **FFB Tuner** (free force feedback) and
**Race Strategy** (paid race engineer, 7-day free trial), sharing one game connection and one set of settings.

## Download

- **Latest release:** see [Releases](https://github.com/WnDTech/WndSimSuite/releases/latest)
- **Website:** [simsuite.wndtech.tips](https://simsuite.wndtech.tips/)

The installer includes both apps. Installed copies update the dashboard and each app automatically from the
releases here and in the apps' own release pages.

## Source code

WND SimSuite is closed-source. This repository only hosts releases.
